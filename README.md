# 🐍 Python — Projeto Girls Tech

Repositório desenvolvido como parte do **Projeto Girls Tech**, com foco no ensino e na prática de **Python**, abrangendo conteúdos do nível básico ao avançado.

O curso está organizado em **2 semanas intensivas**, agrupando os 4 módulos originais em blocos progressivos, combinando conceitos fundamentais, exercícios práticos, desafios de programação, desenvolvimento de projetos e uso de Inteligência Artificial como apoio ao aprendizado.

### 📚 Conteúdo

**Semana 1 — Fundamentos, lógica e estruturas (Módulos 1+2)**
- Sintaxe, variáveis, tipos de dados e operadores
- Lógica de programação: condicionais e loops
- Estruturas de dados: listas, dicionários e tuplas
- Funções

**Semana 2 — Arquivos, POO, bibliotecas e projeto final (Módulos 3+4)**
- Manipulação de arquivos e tratamento de exceções
- Módulos e Programação Orientada a Objetos (POO)
- Bibliotecas do ecossistema Python e automação
- Manipulação de dados e desenvolvimento de projeto prático
- Uso de Inteligência Artificial como apoio à programação (boas práticas, revisão de código, depuração assistida)

### 📖 Material de apoio

Além das aulas, o repositório inclui um **e-book de estudo** (`ebook-python-girls-tech.pdf`) com o conteúdo de cada semana aprofundado — indicado para quem quer reforçar o aprendizado fora do horário de aula, revisar conceitos no próprio ritmo ou se adiantar aos próximos tópicos.

### 🎯 Objetivo

Desenvolver uma base sólida em Python por meio da **aprendizagem prática**, estimulando a resolução de problemas, o desenvolvimento de aplicações, a aplicação dos conceitos em projetos reais e o uso responsável de ferramentas de IA no processo de aprendizagem.

### 🛠️ Tecnologias

- Python
- Git e GitHub
- Bibliotecas e recursos do ecossistema Python
- Ferramentas de IA para apoio à programação (uso orientado)

O repositório contém **materiais de estudo, exemplos de código, exercícios, o e-book de apoio e projetos desenvolvidos ao longo da formação**.
